# Assets de Wandra

En la previsualización, cada bloque rotulado **IMAGEN** o **VIDEO** permite arrastrar un archivo o elegirlo desde el equipo para verlo inmediatamente. Esa previsualización es local y no guarda el archivo todavía.

Cuando los assets finales estén listos, guárdalos en esta carpeta con estas referencias:

- `hero-botella-01.webp` a `hero-botella-06.webp`: secuencia del hero, PNG/WebP transparente.
- `ritual.mp4`: video sin audio, preferiblemente 1080 × 1920 o 1920 × 1080.
- `ritual-escena.webp`: escena de consumo.
- `origen-fermentacion.webp`: proceso de fermentación.
- `sabor-01.webp` a `sabor-04.webp`: botellas transparentes por sabor.
- `pack-01.webp` a `pack-03.webp`: fotografías de packs.
- `comunidad.webp`: mesa o comunidad Wandra.

La siguiente fase puede conectar estas rutas directamente a la página y reemplazar los marcadores de carga.
